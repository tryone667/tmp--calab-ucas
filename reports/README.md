### 1.2 体例格式（来源：A01_实验报告撰写建议.pdf，原则性要求）

1. 报告应有题目，表明是哪个实践专题。
2. 报告应写明作者是谁（姓名、学号）。
3. 是文章不是幻灯片。
4. 报告不需要放目录。
5. 报告中各级标题、正文、图表标题、表中内容的格式（如字体、段落）应统一，具体格式由学生自行选择。
6. 尽量用 visio、draw.io 等作图软件画图，再插入到最终的报告中。

### 1.3 行文建议（同上）

- 决定质量高低的首先是内容，其次是行文，最后才是体例格式；篇幅与质量没有必然关系，**不要为凑页数说车轱辘话，也不要放 AI 生成的徒有形式而无实质的内容**。
- 应说明**设计思路**，阐述设计方案中的**重点、难点或自觉巧妙之处**。
- 记录一些**“高质量” bug 的定位过程**；也可以是任务划分、联合调试等**团队协作中的得失体会**。
- **一图胜千言**：说明数据通路最好配结构设计框图，说明控制过程最好配状态转换图、流程图，说明复杂设计错误不妨结合时序图。
- 提交前自己通读一遍，至少做到语句通顺。

课程 PPT 里 **实践任务编号 = 课程发布包的 exp 编号**，例如“实践任务 7”就是 `exp7.zip`。

| 发布包 | 是什么 | 前置/专题 |

| exp1 | 跑马灯（Vivado / FPGA 入门操练） | **前置操练，没有对应专题报告** |
