怎么看

  1. 比较转移（+4 条）：blt/bge/bltu/bgeu 都在 ID 判定——有符号用 $signed 比较、无符号直接比（新增 rj_lt_rd_s / rj_lt_rd_u 两个比较器），和 beq/bne 共用同一套 cancel 冲刷。
  2. 字节/半字访存（+6 条）：ld.b/ld.h/ld.bu/ld.hu/st.b/st.h——写侧用“移位掩码 + 复制数据”（st.b：0001 按 addr[1:0] 移位；st.h：0011 按 addr[1] 移位；wdata 复制填满总线），读侧在 MEM 拍按地址选字节/半字并做符号/零扩展。
  3. ls_type[4] 随流水线：0 无 / 1 st.b / 2 st.h / 3 st.w / 4 ld.b / 5 ld.h / 6 ld.w / 7 ld.bu / 8 ld.hu——替代原来的单个 mem_we，从 ID 一路带到 MEM。
  4. 其余同 exp10：三路前递、load-use / div 停摆、①②③④ 冲刷。
