怎么看

  1. 本版只解决"能跑"：五级流水 + 同步 RAM 模型成型；分支在 ID 判定、只改 PC（④ 改道），不撤销错路指令——因为测试镜像里错路位置都插了 NOP。
  2. 数据冒险不处理：没有检测比较器、没有停顿（id_stall ≡ 0），相关指令之间靠镜像插 NOP 拉开距离。
  3. 和 exp8 对着看：exp8 图多出"冒险检测"一小块 + 三根红色撞车线 + 三根虚线反压，前端还多 ①②③ 三处 cancel 门控；本图这些都没有——这就是 exp8 的增量。

对照：exp8 收束图、exp8 布线可拖版。口径：入/出 = 图上引脚数；clk / resetn 全局省略。
